一、核心改进路径

二、详细改动记录
-----------------------------------------------------------

1. 标签改造：绝对收益 → 相对超额收益排名
   文件: train.py (_build_label_and_clean函数)
   修改内容:
     - 计算个股5日绝对收益: abs_return = (open_t5 - open_t1) / open_t1
     - 计算当日市场平均收益: market_return = groupby('日期')['abs_return'].mean()
     - 计算超额收益: excess_return = abs_return - market_return
     - 将超额收益转化为百分位等级标签: label = rank(pct=True, ascending=False) * 100
   效果: 0.024 → 0.030

2. 特征筛选：相关性去重
   文件: utils.py (engineer_features_corr_filtered函数)
   修改内容:
     - 通过相关性分析发现38个高度冗余特征(相关系数>0.95)
     - 特征数从197个降至159个
     - 移除类别: 价格特征(收盘/最低/最高)、均线特征(sma/ema/boll_mid)、
       分位数特征(QTLU/QTLD)、极值特征(MAX/MIN)等
   效果: 0.030 → 0.030（稳定，信号密度提升）

3. 学习率调整
   文件: config.py
   修改内容:
     - learning_rate: 1e-5 → 2e-5
   理由: 特征减少后模型复杂度降低，需要更高学习率加速收敛
   效果: 0.030 → 0.031

三、辅助改进
-----------------------------------------------------------

4. 评估指标与评分脚本对齐
   文件: train.py (calculate_ranking_metrics函数)

     - targets用于评估(真实涨跌幅)，relevance用于训练(排名标签)

5. pairwise_loss修复：只保留排名方向

   修改内容:
     - 使用torch.sign(true_diff)替代直接差值比较
     - 排名值是序数，只关心顺序不关心绝对差值

6. 滚动窗口验证框架
   文件: train.py (generate_rolling_windows, train_single_window, run_rolling_validation函数)

     - 报告平均收益、正收益窗口比例、最大连续亏损等指标

十二、集成融合策略（成功）
-----------------------------------------------------------

1. 双层融合策略
   文件: code/src/ensemble_predict.py
   修改内容:
     - 加载Transformer和LightGBM两个模型
     - 分别对300只股票进行预测
     - z-score标准化: 消除两个模型的分数尺度差异
     - 排名融合: rank_blend = 0.6 * (1/t_rank) + 0.4 * (1/l_rank)
     - 分数融合: score_blend = 0.6 * t_norm + 0.4 * l_norm
     - 最终融合: ensemble = 0.5 * score_blend + 0.5 * rank_blend
     - 按ensemble分数排序选择Top5股票
   效果: score_self得分0.1049（提升+94%）

2. 融合策略对比
   - 简单加权融合: 得分-0.0053（失败）
   - 排名融合+分数融合: 得分0.1049（成功）
   - 成功原因: 排名融合对分数尺度不敏感，两个模型的排名信息互补
