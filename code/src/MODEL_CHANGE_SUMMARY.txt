一、改进效果
-----------------------------------------------------------
基准分数: 0.024
改进后分数: 0.030
提升幅度: +25%

二、核心改动
-----------------------------------------------------------

1. 标签改造：绝对收益 → 相对超额收益排名
   文件: train.py (_build_label_and_clean函数)
   改动内容:
     - 计算个股5日绝对收益: abs_return = (open_t5 - open_t1) / open_t1
     - 计算当日市场平均收益: market_return = groupby('日期')['abs_return'].mean()
     - 计算超额收益: excess_return = abs_return - market_return
     - 将超额收益转化为排名标签: label = groupby('日期')['excess_return'].rank()
   原理: 排序任务应优化相对排名，而非绝对收益

2. 评估指标与评分脚本对齐
   文件: train.py (calculate_ranking_metrics函数)
   改动内容:
     - 添加top5_return指标: Top5股票等权平均收益率
     - 确保评估逻辑与test/score_self.py一致
     - targets用于评估(真实涨跌幅)，relevance用于训练(排名标签)

3. 特征筛选：去除高度冗余特征
   文件: utils.py (engineer_features_corr_filtered函数)
   改动内容:
     - 通过相关性分析发现38个高度冗余特征(相关系数>0.95)
     - 移除后特征数从197个降至159个
     - 移除的特征类别:
       * 价格特征: 收盘、最低、最高(与开盘相关系数>0.999)
       * 均线特征: sma_5/sma_20/ema_12/ema_26/ema_60/boll_mid
       * 分位数特征: QTLU/QTLD系列
       * 极值特征: MAX/MIN系列
       * 其他: KLEN/OPEN0/macd_signal等
   原理: 冗余特征增加噪声和过拟合风险，降低信号密度

4. pairwise_loss修复：只保留排名方向
   文件: train.py (WeightedRankingLoss类)
   改动内容:
     - 使用torch.sign(true_diff)替代直接差值比较
     - 排名值是序数，排名1和2的差距与排名50和51的差距等价
   原理: 排序任务只关心顺序，不关心绝对差值

五、关键经验
-----------------------------------------------------------
1. 信号密度 > 特征数量：获奖团队从142个特征精简到20个后性能显著提升
2. 评估指标必须与最终评分对齐：前期使用NDCG验证但与实际评分相关性不强
3. 标签应与任务目标一致：排序任务应使用排名标签而非回归标签
4. 逐步验证：每次只改一个参数，观察效果后再继续

六、下一步建议
-----------------------------------------------------------
1. 滚动窗口验证 + 空窗期：严格按时序切分，留出5天空窗期避免泄漏
2. 超参数两阶段搜索：先单参数扫描，再网格组合搜索
3. 权重优化与风险控制：根据预测分数分配权重，添加单票上限和行业分散度约束
4. Ensemble融合：多个模型预测结果融合
